# Distribution

One Markdown source, four channels. Everything here is generated from `manuscript/`, which stays the single source of truth.

| Channel | Purpose | Status |
|---|---|---|
| GitHub Pages | Canonical home. You own it, permanent URL. | **Live** at https://samisbakedham.github.io/EconBook/ |
| Substack | Reach. This is how the book actually gets read. | 12 posts drafted in `substack/` |
| Leanpub | The downloadable object: EPUB, PDF, Kindle. | `manuscript/Book.txt` and `Sample.txt` ready |
| SSRN | Credibility with economists, who actually search it. | Abstract and JEL codes in `ssrn/` |

## Substack

**Create the publication yourself** at substack.com. I cannot sign you up, and you should not want me to.

Then paste the posts from `substack/` in numbered order. Each one is complete: title, standfirst hook, chapter text, and a forward pointer to the next.

### On the running order

The posts are **not in chapter order**, and this is deliberate.

Post 1 is Chapter 6, "Nobody Goes to Space." It is the most shareable thing in the book: a counterintuitive result with a clean argument and a memorable line, and it needs almost no setup. Leading with Chapter 1 means opening on transversality conditions, which is correct as a book and fatal as a first newsletter post to zero subscribers.

Post 2 returns to Chapter 1 and the book runs in order from there. The first post says explicitly that this is what is happening, so nobody is confused.

### Cadence

Weekly, same day each week, twelve weeks. Do not post twice in a week to catch up, and do not go dark for two. The value of a serial is that it is a habit.

### Realistic expectations

The first three posts will feel like shouting into a void. That is normal and not a signal. Serialized nonfiction compounds: post 6 gets read because post 1 was good, and the archive keeps earning after the run ends. Judge it at twelve weeks, not at three.

## Leanpub

Leanpub reads a `manuscript/` folder with a `Book.txt` listing files in order. You already have exactly that, so setup is:

1. Create a book at leanpub.com, choosing **GitHub** as the source.
2. Point it at `samisbakedham/EconBook`.
3. Set the price to **free**, or to "reader decides" with a minimum of zero.
4. Click Preview, then Publish.

`Sample.txt` controls the free excerpt. It is set to Chapter 1 plus "Nobody Goes to Space," on the same logic as the Substack running order: give away the chapter most likely to make someone want the rest.

Leanpub regenerates EPUB, PDF and MOBI on every push, so the book updates itself as you close out citations.

## SSRN

Materials are in `ssrn/abstract.md`: a full abstract, keywords, and seven JEL codes.

**Do this one last.** SSRN's readership checks citations, and twenty attributions in the notes are still open. A reviewer in that audience will go straight to the Chapter 1 treatment of transversality conditions, which is exactly the load bearing claim that is not yet sourced.

Submission needs a single PDF:

```
brew install pandoc basictex
./distribution/build-combined.sh
```

That writes `distribution/out/terminal-value.pdf` and `.epub`. Without pandoc it still writes the combined Markdown, which is useful on its own.
